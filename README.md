# Aprenda Xadrez ♟️

## Sobre o Projeto

**Aprenda Xadrez** é um site de caráter educativo, desenvolvido com o objetivo de ensinar conceitos teóricos do xadrez, além de apresentar fatos e curiosidades sobre o jogo.

O projeto foi pensado para atender diferentes perfis de usuários, desde iniciantes que estão tendo o primeiro contato com o xadrez até jogadores mais experientes que desejam revisar conceitos.

Este site foi desenvolvido para fins acadêmicos, como parte do processo de aprendizagem de programação web básica, priorizando simplicidade, clareza e boa organização do conteúdo.

## Tecnologias Utilizadas

O desenvolvimento do site foi realizado utilizando **HTML5** para a estruturação do conteúdo e **CSS3** para a estilização visual das páginas. As tecnologias foram escolhidas com o objetivo de praticar conceitos fundamentais do desenvolvimento web, sem o uso de bibliotecas ou frameworks externos.

## Como Executar o Projeto

1. Acesse a pasta `/html`
2. Abra o arquivo `index.html` em qualquer navegador web moderno

Não é necessário servidor ou dependências adicionais.
